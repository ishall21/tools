## 📌 About

This repository is a growing directory of websites that provide useful software, utilities, documentation, and technical resources. It starts with resources similar to the **TestDisk & PhotoRec** download page and can expand into system recovery, bootable USB tools, operating systems, networking, cybersecurity, and IT troubleshooting.

The goal is to make useful resources easy to find without having to search the web from scratch.

## 🔎 How to Use This Directory

1. Browse the category that matches your task.
2. Open the listed website and confirm that it fits your needs.
3. Prefer the official developer or project website for downloads.
4. Check system requirements, release notes, license terms, and file hashes when available.
5. Suggest new links through an issue or pull request.

## 🛡️ Safety Guidelines

- **Prefer official sources.** Avoid repackaged installers and download mirrors you cannot verify.
- **Verify downloads.** Check published checksums or digital signatures when available.
- **Be careful with recovery tools.** If a disk may be failing, minimize writes to it. Recover files to a different drive whenever possible.
- **Use security tools responsibly.** Only scan systems and networks you own or have permission to assess.
- **Review every link.** A link in this directory is a reference, not a guarantee of safety, availability, or endorsement.
